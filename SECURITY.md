# Security

This repository is a static marketing site. It must never contain:

- live account numbers or real net liquidation
- feed URLs, Access credentials, API tokens, or Keychain secrets
- private keys, `.p8` files, or Cloudflare / GitHub tokens

## Reporting a vulnerability

Please email the copyright holder at the address on the GitHub profile
[MuratPod](https://github.com/MuratPod). Do not open a public issue for
credentials or personal trading data.

If you find a secret in a commit, say so privately first so it can be rotated
and removed.
