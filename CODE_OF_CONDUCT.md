# Code of Conduct

We follow the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

Be respectful, assume good faith, and do not share anyone’s account data,
credentials, or real trading figures in issues, pull requests, or chat.

Enforcement: the repository owner, via the contact on the
[MuratPod](https://github.com/MuratPod) GitHub profile.
